# 实时会议翻译（Live Meeting Translator）

[English](README.en.md)

网页版实时会议翻译工具：麦克风收音 → 语音识别（俄语 / 英语）→ 免费翻译接口实时转成简体中文，原文与译文分栏对照，支持语音播报与纪要导出。纯静态 HTML，无后端，零费用。

## 功能

- 实时收音转写：浏览器语音识别，支持俄语（ru-RU）、英语（en-US），以及自动识别（按文字自适应切换）
- 免费翻译（零 key、零 token），自动按顺序挑能用的源：
  1. 浏览器内置翻译模型（Chrome 138+，本地推理；设置里点「下载 / 检查」下好一次，之后离线可用、不耗额度）
  2. MyMemory 免费接口（主力，直连，CORS 放开）
  3. Google 免费接口（经公共 CORS 代理中转，兜底，国内网络常连不上）
- 展示模式：双栏对照 / 单栏对照 / 仅原文 / 仅译文，字号可调，支持全屏（投影友好）
- 语音播报：译文中文朗读（浏览器 TTS）
- 术语表：译后字面替换，统一人名、品牌名、行业词
- 手动输入：不方便出声时可打字翻译
- 纪要导出：一键导出带时间戳的文本纪要，也可复制全文

## 快速开始

1. 用 Chrome 或 Edge 打开 `index.html`（语音识别需要 https 或 localhost；直接双击本地文件可用，若浏览器限制麦克风，起个本地服务即可）：

   ```bash
   python3 -m http.server 8000
   # 浏览器打开 http://localhost:8000
   ```

2. 点麦克风开始。发言实时出现在左栏，译文出现在右栏。
3. （可选）右上角「⚙ 设置」里填术语表；在 mymemory.translated.net 免费注册一个 Key 填进去，每日翻译额度从 5,000 词升到 50,000 词；想彻底不看额度，点「下载 / 检查」把浏览器内置翻译模型下下来（一次几十分钟会议足够，断网也能译）。

不需要任何付费 API Key，翻译请求全部走免费公开接口。

## 免费额度说明

- MyMemory 匿名额度：每天约 5,000 词，够一般会议用；长时间重度使用建议免费注册 Key。
- 免费接口偶有限流，应用会自动切换下一个免费源；全部失败时会提示稍后重试。

## 部署

静态文件，可直接部署 GitHub Pages 或任意静态托管。

## 浏览器支持

| 能力 | Chrome / Edge | Safari | Firefox |
|---|---|---|---|
| 语音识别 | ✅ | 部分版本 | ❌ |
| 手动输入翻译 | ✅ | ✅ | ✅ |

## 说明

- 语音识别由浏览器内置引擎完成，Chrome 的语音识别要连 Google 服务器；网络访问不到 Google 时会报「识别服务连不上」，这时先用「手动输入」。
- 单次翻译按 500 字符上限切段（MyMemory 的限制），长句子会自动拆开再拼回。
- 多个发言连着来时翻译请求串行排队，避免免费接口 429 限流。
- 翻译质量为机器翻译水平；善用术语表配置对齐专有名词。
